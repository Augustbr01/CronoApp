# `features/mixer/` — mixer e transporte

UI do mixer (RF-05): dois faders verticais (MASTER/FUNDO), VU-meters de três
faixas, indicação de MUTE, indicador NO AR/STANDBY, toast de fade. Faders
operáveis por toque (Pointer Events) e por teclado (`role="slider"`).

> Preenchido na **Etapa 4** (liga a UI ao motor de `audio/`).
